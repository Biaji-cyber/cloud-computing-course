**Reflection: Cloud Concepts in Everyday Technology**

Cloud computing has become a regular part of my daily life, even when I do not always notice that I am using it. Three cloud services that I frequently use are Google Drive, Canva, and Messenger. These applications help me with schoolwork, communication, and other everyday activities.

**Google Drive** is an example of Software as a Service (SaaS) and uses a Public Cloud deployment model. I use Google Drive to store school documents, presentations, and other files online. Since I can access my files using different devices without managing the servers or infrastructure, it demonstrates how SaaS provides ready-to-use applications through the internet.

**Canva** is also an example of SaaS and a Public Cloud service. I use Canva to create presentations, posters, and other school-related designs. The application provides the tools and storage I need without requiring me to install or maintain the underlying infrastructure. This makes creating and editing designs more convenient.

**Messenger** is another SaaS application that uses a Public Cloud deployment model. I use it to communicate with classmates, friends, and other people. Messages and other features are supported by cloud infrastructure managed by the service provider, allowing users to communicate through the internet.

Git and GitHub are also important when working with cloud projects because they provide version control. Git keeps track of changes made to files, allowing developers to see previous versions and recover work when necessary. GitHub provides an online platform where team members can store repositories, collaborate, review changes, and manage project files. This can help prevent errors because changes can be tracked instead of being overwritten without a record.

Overall, cloud computing makes many activities more convenient and accessible. Using Google Drive, Canva, and Messenger has helped me realize that cloud technology is already an important part of my everyday life.
